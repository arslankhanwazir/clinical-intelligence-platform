# Security Policy

This project is in foundation stage and is not approved for clinical use. No security certification or independent penetration test is claimed.

## Data handling
- Synthetic data only during development and evaluation.
- Never commit patient information, credentials, API keys, private keys, tokens, or confidential third-party material.
- Keep local environment files and private datasets outside version control.
- Do not send secrets, patient information, or confidential code to AI coding assistants or external services.

## Reporting a vulnerability
Do not publish exploit details, patient information, credentials, or sensitive logs in public issues. Until a dedicated security contact is published, report suspected issues privately to the project owner through an established private channel. Include affected component, impact, and safe reproduction steps; do not access or modify data that is not yours.

## Assurance status
No security certification, regulatory clearance, clinical safety validation, or external penetration test is claimed. Any future assurance claim must identify its scope, date, assessor, and evidence.
