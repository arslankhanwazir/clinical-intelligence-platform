# Definition of Done

A task is complete only when all applicable items below are satisfied:

- Scope, non-goals and acceptance criteria are recorded.
- Change is in the correct branch and has a human-reviewed diff.
- Tests are added or the reason tests are not applicable is documented.
- Relevant tests pass; failures are reported, not hidden.
- Input validation, authorization, tenant boundaries and error handling are considered.
- No secrets, real patient data, confidential third-party material or unlicensed assets are added.
- Dependencies, models, datasets and assets have reviewed licences and versions.
- Documentation and ADRs are updated where behavior or architecture changes.
- Clinical content or rules have qualified clinician review before they are used in a clinical workflow.
- Security/privacy/regulatory impact and rollback implications are recorded.
- No unsupported claims of clinical safety, accuracy, certification or regulatory approval are made.
