## Source-control policy

For each approved source, retain publisher, exact title, jurisdiction, edition/version, publication date, effective date, URL, access date, authorised file checksum if retained, exact licence/permission, named reviewer, review date, sections approved, excluded sections, superseded status and change history.

Do not ingest any candidate source into operational retrieval, model context or rule packs until clinical suitability, exact version, rights/permission and reviewer approval are recorded. Public accessibility is not the same as commercial reuse permission. A clinical approval does not replace a copyright licence, and a copyright licence does not replace clinical approval.
