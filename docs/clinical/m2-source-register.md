## Source-control policy draft

For each candidate source, retain: publisher, exact title, jurisdiction, edition/version, publication date, effective date if any, URL, access date, file checksum if an authorised copy is retained, copyright/licence, permissions, reviewer, review date, sections approved, superseded status and change history.

Do not ingest a source into production retrieval, model context or rule packs until its clinical suitability, exact version, licence/permission and reviewer approval are recorded. Public accessibility is not the same as permission for commercial reuse.
